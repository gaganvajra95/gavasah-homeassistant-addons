# GAVASAH Home Assistant Add-ons Repository

Official Home Assistant OS add-on repository for GAVASAH Smart Living, KNX Automation, and Multi-Tenant Cloud Fleet Management.

## Available Add-ons

| Add-on | Description | Architecture |
| :--- | :--- | :--- |
| **Gavasah Cloud Agent** | Telemetry Heartbeat, RAUC A/B Slot Health, AutoSSH Ingress, & KNXnet/IP Relay | `aarch64`, `amd64`, `armv7` |

---

## Installation via Home Assistant UI

1. Open your Home Assistant instance.
2. Navigate to **Settings** &rarr; **Add-ons** &rarr; **Add-on Store**.
3. Click the **three dots (⋮)** in the top right corner and select **Repositories**.
4. Paste this repository URL:
   ```
   https://github.com/gaganvajra95/gavasah-homeassistant-addons
   ```
5. Click **Add** &rarr; **Close**.
6. Find **Gavasah Cloud Agent**, click **Install**, and configure your client credentials.
